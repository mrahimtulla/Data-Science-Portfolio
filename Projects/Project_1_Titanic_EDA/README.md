# Exploratory Data Analysis of the Titanic Dataset

## Overview

This project performs an exploratory data analysis (EDA) on the Titanic dataset. The goal is to understand the factors that influenced survival in the Titanic disaster.

## Dataset

The dataset is from [Kaggle's Titanic competition](https://www.kaggle.com/c/titanic/data). It contains information about passengers, such as age, sex, class, fare, and whether they survived.

## Project Structure

- `data/`: Contains the dataset (train.csv)
- `code/`: Jupyter notebook for the EDA
- `output/`: Generated plots and summary statistics

## Steps

1. Data Loading and Inspection
2. Data Cleaning
3. Univariate Analysis
4. Bivariate Analysis
5. Multivariate Analysis
6. Conclusions

## How to Run

1. Clone the repository.
2. Navigate to `Projects/Project_1_Titanic_EDA/code/`.
3. Open the Jupyter notebook `titanic_eda.ipynb`.
4. Run the notebook cells.

## Results

Key findings:
- Survival rate was higher for females, higher-class passengers, and children.
- Age and fare had complex relationships with survival.

See the notebook for detailed visualizations and analysis.
