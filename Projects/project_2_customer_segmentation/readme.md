# Project 2: Customer Segmentation using Clustering

## 📊 Project Overview
This project segments mall customers into distinct groups using K-means clustering algorithm.

## 🎯 Business Objective
Help marketing teams develop targeted strategies for different customer segments.

## 📊 Dataset
- **Source**: Mall Customer Segmentation Data
- **Features**: CustomerID, Gender, Age, Annual Income, Spending Score
- **Records**: 200 customers

## 🛠️ Methodology
1. Data Preprocessing & EDA
2. K-means Clustering with Optimal K Selection
3. Cluster Validation & Profiling
4. Business Recommendations

## 📈 Results
- **Optimal Clusters**: 5 distinct segments
- **Silhouette Score**: 0.55
- **Key Segments**: High/Low Spenders, Target Customers, etc.
